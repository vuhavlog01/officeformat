# OfficeFormat - Phần Mềm Lập & Xuất Lịch Công Tác Tuần Chuẩn Thể Thức

Ứng dụng web hỗ trợ soạn thảo, xem trước A4 trực quan thời gian thực (Live Preview) và bóc tách / xuất file Word (`.docx` / `.doc`) chuẩn Hướng dẫn 05-HD/VPTW và Nghị định 30/2020/NĐ-CP.

## Tính năng chính:
- Tự động chia cột Buổi Sáng / Buổi Chiều, hợp nhất hàng (merge cells) các thứ trong tuần.
- Tự động nhận diện chữ đỏ (sự kiện quan trọng) theo chuẩn Hướng dẫn 05.
- Hỗ trợ nạp lịch từ file Word cũ (`.doc` và `.docx`) thông qua LibreOffice Headless.
- Xem trước trực quan A4 tỷ lệ chuẩn, có thể xuất Word (.docx) chỉ với 1 click.
